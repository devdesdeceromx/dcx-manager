# DevDesdeCeroMx

Sitio público bilingüe de DevDesdeCeroMx, enfocado en soluciones digitales para negocios de Nuevo Progreso que atienden clientes de México y Estados Unidos.

## Desarrollo local

```bash
npm install
npm run dev
```

Las variables públicas de Supabase se configuran como secretos del entorno de despliegue. Nunca se incluyen credenciales privadas en el repositorio.
